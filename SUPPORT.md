# Support

Kimi Code CLI Launcher is maintained by Mikesoft.

## Bug Reports and Feature Requests

Use GitHub Issues for reproducible bugs, regressions, and feature requests:

- https://github.com/TheStreamCode/vscode-kimi-code-cli-launcher/issues

Include:

- VS Code or compatible-editor version
- operating system
- single-folder or multi-root workspace
- configured `kimiCodeCliLauncher.cliCommand` value, without secrets
- steps to reproduce
- expected and actual result
- visible terminal error, with sensitive data redacted
